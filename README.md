# Personal Portfolio – Jacob Brandhild



A personal portfolio website created as part of my blockchain and HTML\&CSS development courses. The website introduces me, presents selected projects, and provides a way to get in contact.



## About the Project



The purpose of this project is to build a personal portfolio that works as an online CV and showcases my background, interests, and projects.





## Features



- Responsive layout for desktop and mobile devices

- Navigation links to the main sections of the website

- Introduction and personal profile section

- Project portfolio with descriptions

- About me section and skills overview

- Contact form with input validation

- Semantic HTML structure and accessibility considerations



## Technologies



- HTML5

- CSS3

- Git and GitHub

- HTML5 Boilerplate as the starting template

- Figma for wireframes and design planning [View wireframes in Figma](https://www.figma.com/design/wSoTOB4dCkCK2lCz8lfECk/Untitled?node-id=0-1&t=GRkT0tHocfjrL8v7-1)
